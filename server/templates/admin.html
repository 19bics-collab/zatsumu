設定 （撮影設定はクライアントの次の撮影サイクルから自動反映されます）

管理者トークン（あなたのログイン用）

この端末でログイン中のあなた自身のトークンです。 別の端末・ブラウザで管理画面にログインするときに使います。 他人には渡さないでください（このトークンで管理者としてログインできます）。

••••••••

「ログインURLをコピー」で /admin#token=… 付きのURLをコピーできます。 そのURLを別端末で開けば、トークン入力なしでログインできます（URLの取り扱いにも注意）。

会社・表示

会社名はヘッダーに表示され、勤務時間帯はタイムラインに目安の帯として 表示されます。作業区分はメンバーが在席中に切り替えられ、先頭が既定です。

画面キャプチャ

勤務・保存・アラート

予定勤務時間を基準に、月次レポートと個人ページで残業/不足を集計します。 保存日数を超えたキャプチャは自動削除、連続在席がアラート時間を超えると⚠表示・通知されます。

画面停滞アラート（離席検知）

各キャプチャを直前の画像と見比べ、一致率がしきい値以上の状態が 指定回数つづくと「画面が変化していない（離席の可能性）」として通知します。 一致率を上げる（例 98%）ほど厳しく、下げるほど小さな変化でも停滞とみなします。

退勤リマインド・稼働率

終業時刻を過ぎても退勤していない人に、本人（と通知先）へ退勤を促します。 稼働率は、PCの無操作がこの秒数未満だったキャプチャの割合で算出します（PC版クライアントのみ計測）。

通知（Slack / メール）

スタッフがその日の日報を保存したら、下の通知先へ本文をメール（/Slack）します。 連投を防ぐため通知は1人1日1回です。

Slack は Incoming Webhook の URL を貼り付けるだけ。メールは SMTP の設定が必要です。 保存後に「テスト送信」で疎通確認できます。

「テスト送信」は設定済みの全チャネル（Slack/メール）へ。下のフォームは 入力した1つのメールアドレス宛にだけ送って、SMTPと宛先の疎通を確認できます（保存後に実施）。

メール受信（IMAP）

共有の受信箱（例: info@…）をIMAPで定期取得し、「メール」画面に優先度順で 表示します。受信箱のメールは変更しません（既読も付きません）。 返信の送信には左の通知欄のSMTP設定を使います。

AI返信（Claude）

APIキーを設定すると、優先度の判定と返信文の下書きをAI（Claude）が行います。 未設定でもキーワードによる分類と定型文の下書きで動作します。 返信は必ず内容を確認してから送信してください。

青=在席（斜線は勤務中・クリックで修正）、●=画面キャプチャ（クリックで表示、←→で前後に移動）、●=画面停滞（画面が動いていない＝離席の可能性）。
